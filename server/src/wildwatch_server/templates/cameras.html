Add a camera

Both methods enroll the RPi automatically. After it shows up in the Pending approval list above, click Approve and uploads start. The "from your computer" path needs a few tools locally -- see requirements.

From your computer (with SSH access)

Run this on your laptop. It clones the repo into a temporary directory, discovers the RPi on your network, copies the code over SSH, runs the system setup, and calls the enrollment endpoint:

{% set cmd_local = 'bash -c "$(curl -fsSL https://raw.githubusercontent.com/didouye/wildwatch/main/_recovery/install.sh)" -- --server ' ~ server_url %} 
{{ cmd_local }}
From the RPi (one-line SSH install)

SSH into the RPi as dietpi and run:

{% set cmd_rpi = "curl -fsSL https://raw.githubusercontent.com/didouye/wildwatch/main/_recovery/setup.sh | bash -s -- --server " ~ server_url %} 
{{ cmd_rpi }}
