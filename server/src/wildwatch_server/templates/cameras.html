Add a camera

Both methods enroll the RPi automatically. After it shows up in the Pending approval list above, click Approve and uploads start.

From your computer (with SSH access)

Run this on your laptop. The script discovers the RPi on your network, copies the code over SSH, runs the system setup, and calls the enrollment endpoint: 

uv run https://raw.githubusercontent.com/didouye/wildwatch/main/_recovery/install_wildwatch.py \
  --server {{ server_url }}
From the RPi (one-line SSH install)

SSH into the RPi as dietpi and run:

curl -fsSL https://raw.githubusercontent.com/didouye/wildwatch/main/_recovery/setup.sh \
  | bash -s -- --server {{ server_url }}
