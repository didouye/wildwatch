# V1.2 PR 1.5 -- Agent version visibility + in-place update flow

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (or subagent-driven-development) to implement this plan task-by-task.

**Goal:** Each approved camera shows the agent version it is running. When that version is older than the server's expected `LATEST_AGENT_VERSION`, an "Update available" banner with a copy-paste install one-liner appears -- mirroring the existing "Add a camera" modal. Cameras enrolled before V1.2 (no agent installed yet) show an "Install agent" CTA.

**Architecture:** The server hardcodes the latest agent version it expects (`LATEST_AGENT_VERSION` constant). `_camera_card_context` compares it to `last_heartbeat.agent.version` and emits an `agent_status` of `"none" | "outdated" | "current"`. The card template renders a badge + an "Update camera" button that opens a modal with the appropriate one-liners. A new `_recovery/update.sh` script does the in-place update (preserves config.toml + camera token, installs/refreshes agent service, restarts both services).

**Tech stack:** FastAPI + Jinja2 + htmx (server), bash + uv + systemctl (RPi script).

**Companion design:** `docs/plans/2026-05-06-camera-control-plane-design.md` (general control plane), this plan extends PR 1 to make the agent self-upgradable.

### Task 5: `_recovery/update.sh`

**Files:**
- Create: `_recovery/update.sh`

**Steps:**

1. Write the script. Goals:
   - Idempotent (re-runnable safely)
   - Preserves `~/wildwatch/config.toml` (do NOT touch it)
   - Pulls latest code into `~/wildwatch-src/`
   - Rebuilds capture + agent venvs
   - Refreshes systemd unit files, tmpfiles.d, sudoers
   - daemon-reload, enable + start agent, restart capture
   - Loud failure messages (set -e); echoes each step

```bash
#!/usr/bin/env bash
# WildWatch -- in-place RPi update.
#
# Usage on the RPi (or via SSH from your laptop):
#   curl -fsSL https://raw.githubusercontent.com/didouye/wildwatch/main/_recovery/update.sh | bash
#
# Preserves ~/wildwatch/config.toml (and therefore the camera token + server URL).
# If the install is missing entirely, this script exits with a clear error --
# in that case run setup.sh instead.

set -euo pipefail

REPO_URL="${WILDWATCH_REPO:-https://github.com/didouye/wildwatch.git}"
SRC_DIR="${WILDWATCH_SRC:-$HOME/wildwatch-src}"
CONFIG_DIR="${WILDWATCH_CONFIG_DIR:-$HOME/wildwatch}"

echo "==> WildWatch update"
echo "    Repo : $REPO_URL"
echo "    Src  : $SRC_DIR"
echo "    Cfg  : $CONFIG_DIR"
echo

if [[ ! -d "$SRC_DIR/.git" ]]; then
    echo "error: $SRC_DIR is not a git checkout. Use setup.sh for a fresh install." >&2
    exit 1
fi
if [[ ! -f "$CONFIG_DIR/config.toml" ]]; then
    echo "error: $CONFIG_DIR/config.toml not found. Use setup.sh for a fresh install." >&2
    exit 1
fi

echo "==> Step 1/6: pulling latest code"
( cd "$SRC_DIR" && git fetch --all --prune && git reset --hard origin/main )

echo "==> Step 2/6: refreshing capture venv"
( cd "$SRC_DIR/capture" && uv sync )

echo "==> Step 3/6: building/refreshing agent venv"
( cd "$SRC_DIR/agent" && uv sync )

echo "==> Step 4/6: refreshing tmpfiles.d + sudoers"
sudo cp "$SRC_DIR/_recovery/wildwatch-tmpfiles.conf" /etc/tmpfiles.d/wildwatch.conf
sudo systemd-tmpfiles --create /etc/tmpfiles.d/wildwatch.conf
sudo install -m 0440 -o root -g root \
    "$SRC_DIR/_recovery/wildwatch-sudoers" /etc/sudoers.d/wildwatch
sudo visudo -c -q

echo "==> Step 5/6: refreshing systemd units"
sudo cp "$SRC_DIR/capture/systemd/wildwatch-capture.service" /etc/systemd/system/
sudo cp "$SRC_DIR/agent/systemd/wildwatch-agent.service" /etc/systemd/system/
sudo systemctl daemon-reload

echo "==> Step 6/6: restart capture, enable + start agent"
sudo systemctl restart wildwatch-capture
sudo systemctl enable --now wildwatch-agent

echo
echo "==> Update done. Status:"
sudo systemctl is-active wildwatch-capture wildwatch-agent || true
echo "    The next heartbeat (within ~30s) should reach the server with the new agent version."
```

2. `chmod +x _recovery/update.sh`.

3. Sanity check the script: `bash -n _recovery/update.sh` (parse-only).

4. Commit: `feat(v1.2): _recovery/update.sh -- in-place update preserving token`.
